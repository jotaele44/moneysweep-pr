BINDING PROFILE ADMISSION (Cell_Profile pr-grid-v2-cell-profile/1.2)

The profile materializer accepts only Spiderweb-certified rows. The binding
receipt must name Migration_Provenance_Class RECOMPUTED_FROM_SOURCE_COORDINATE,
RECOMPUTED_FROM_SOURCE_GEOMETRY or VERIFIED_CROSSWALK (a
pr-grid-v2-exact-point-binding-receipt/1.0 receipt without one counts as
RECOMPUTED_FROM_SOURCE_COORDINATE); any other receipt fails closed.

Exact rows require Uncertainty_Class=EXACT and one of:
COVERS
INTERSECTS_POSITIVE_AREA
LINE_POSITIVE_LENGTH

INTERSECTS_POSITIVE_AREA additionally requires positive Overlap_Area_m2 and
Cell_Coverage_Fraction > 0 and <= 1.
LINE_POSITIVE_LENGTH additionally requires positive Length_In_Cell_m.

Evidence-gated set rows are admitted as non-exact:
ADMINISTRATIVE_SET requires Uncertainty_Class=ADMINISTRATIVE_ONLY and
Geometry_State=VERIFIED_ADMINISTRATIVE_GEOMETRY.
DERIVED_SET requires Uncertainty_Class=DERIVED and
Geometry_State=VERIFIED_DERIVED_GEOMETRY.
Both also require Confidence=null and the same positive-area evidence as
INTERSECTS_POSITIVE_AREA. A set row counts toward Record_Count and
Non_Exact_Record_Count, never Exact_Record_Count; a set row that misses its
policy fails closed.

APPROXIMATE, INFERRED, UNKNOWN and every other Uncertainty_Class, and every
other Binding_Method, fail closed.
Geometry_Included remains false; canonical geometry stays in spiderweb-pr.
